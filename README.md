# Mandi Platform - Agricultural Market Management System

## Overview
Multi-tenant SaaS platform for managing agricultural markets (mandis).

## Project Structure
- `services/` - Backend microservices
- `client/` - Frontend React application
- `shared/` - Shared code (proto files, utilities)
- `infrastructure/` - Docker, Kubernetes configs
- `scripts/` - Build and deployment scripts

## Getting Started

### Prerequisites
- Node.js 18+
- Docker Desktop
- MongoDB
- Redis
- Kafka

### Installation
```bash
npm install
```

### Run Development
```bash
docker-compose up
```
